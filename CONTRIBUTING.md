# Contributing

* Please use [Conventional Commits](https://www.conventionalcommits.org/) whenever possible.
* Please submit pull requests in English whenever possible. Pull requests written in other languages will not be
  rejected solely for that reason.
* Please discuss significant changes before starting work on them.
* Please keep pull requests focused and avoid unrelated changes.

## AI-Assisted Contributions

AI assistance is allowed, but you must fully understand and review any AI-assisted code before submitting it. You are
responsible for all contributions made with AI assistance, including their behavior and potential consequences.

Please do not submit code that was generated entirely by AI without meaningful review or understanding.

AI-assisted translation of text content is allowed.
