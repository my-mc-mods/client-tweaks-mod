# Gizmo 的客户端调整

[English](./README.md) | [简体中文](./README_zh.md)

一个客户端 Minecraft 模组，为原版客户端提供了一系列简单、可配置的小优化。

## 功能

### 延迟与玩家列表

- **数字延迟** — 在玩家列表的信号格旁显示实际延迟值（例如 42 毫秒），并可选择隐藏信号格。颜色由一组规则决定，第一条匹配的规则生效。
- **客户端 Ping 刷新** — 以可配置的间隔自行发送 ping 请求，并将测得的往返时间用于玩家列表中自己那一行，让延迟数值保持实时，而无需等待服务器更新。默认关闭，设置为 1–29 秒即启用。

### 窗口焦点

- **失焦时帧率上限** — 游戏窗口失去焦点时限制帧率（默认 10 FPS），重新获得焦点后恢复原本的帧率上限。
- **失焦时静音** — 游戏窗口失去焦点时静音所有游戏音频。

### 界面

- **隐藏火焰覆盖层** — 拥有抗火效果或处于创造模式时隐藏第一人称火焰覆盖层，因为此时火焰只是视觉干扰。
- **移除 Realms 按钮** — 从标题界面移除 Realms 按钮，并把其余按钮上移填补空位。
- **隐藏不安全警告提示** — 加入不安全的服务器时，隐藏相应的警告弹窗。
- **语言代码筛选** — 允许在语言选择界面的搜索框中匹配 `en_US`、`enUS` 等语言代码（Minecraft 1.21.11 及更高版本）。
